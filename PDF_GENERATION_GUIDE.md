# PDF Generation System Documentation

## Overview

This PDF generation system provides a modular, reusable approach to creating PDF reports using Puppeteer. The system is built with reusable components for headers, footers, tables, and more.

## Installation

The required packages are already installed:
- `puppeteer` - For PDF generation
- `dayjs` - For date formatting
- `@types/puppeteer` - TypeScript definitions

## Project Structure

```
src/
  utils/
    pdf/
      components.ts   - Reusable HTML components (header, footer, table, etc.)
      styles.ts       - Default CSS styles for PDFs
      generator.ts    - Main PDF generator using Puppeteer
      index.ts        - Exports all PDF utilities
  controllers/
    ledger.controller.ts - Example ledger report controller
  routes/
    ledger.routes.ts     - Example ledger routes
```

## Components

### 1. PDF Generator (`PDFGenerator`)

Main class for generating PDFs from HTML.

```typescript
import { PDFGenerator } from '../utils/pdf';

// Generate PDF
const pdfBuffer = await PDFGenerator.generatePDF({
  html: '<h1>My Report</h1>',
  customStyles: 'h1 { color: blue; }',
  pdfOptions: {
    format: 'A4',
    printBackground: true
  }
});

// Or send directly as response
await PDFGenerator.sendPDFResponse(res, {
  html: htmlContent,
  filename: 'report.pdf'
});
```

### 2. Template Builder (`PDFTemplateBuilder`)

Helps build HTML content programmatically.

```typescript
import { PDFTemplateBuilder } from '../utils/pdf';

const builder = new PDFTemplateBuilder();
builder
  .add('<h1>Title</h1>')
  .add('<p>Content</p>')
  .addPageBreak()
  .add('<h1>Next Page</h1>');

const html = builder.build();
```

### 3. Header Component

```typescript
import { generateHeader } from '../utils/pdf';

const header = generateHeader({
  title: 'My Report',
  subtitle: 'Subtitle text',
```

### 4. Footer Component

### 5. Info Section

Display key-value pairs in a grid layout.

```typescript

const info = generateInfoSection({
  'Report Date': dayjs().format('DD MMM YYYY'),
  'Generated By': 'Admin User',
```

### 6. Table Component

Generate tables with custom columns and formatting.

```typescript
import { generateTable, TableColumn } from '../utils/pdf';

const columns: TableColumn[] = [
  {
    label: 'Date',
    key: 'date',
    align: 'center',
    format: (value) => dayjs(value).format('DD-MM-YYYY')
  },
  {
    label: 'Description',
    key: 'description',
    align: 'left'
  },
  {
    label: 'Amount',
    key: 'amount',
    align: 'right',
    format: (value) => value.toLocaleString()
  }
];

const data = [
  { date: '2026-01-01', description: 'Item 1', amount: 1000 },
  { date: '2026-01-02', description: 'Item 2', amount: 2000 }
];

const table = generateTable(columns, data, {
  showTotal: true,
  totalLabel: 'Total',
  totalColumns: {
    description: 'Grand Total',
    amount: 3000
  }
});
```

## Complete Example: Creating a Report Controller

```typescript
import { Request, Response } from 'express';
import dayjs from 'dayjs';
import {
  PDFGenerator,
  PDFTemplateBuilder,
  generateHeader,
  generateTable,
  generateInfoSection,
  TableColumn
} from '../utils/pdf';

export const generateMyReport = async (req: Request, res: Response) => {
  try {
    // 1. Fetch your data
    const data = await fetchDataFromDatabase();

    // 2. Define table columns
    const columns: TableColumn[] = [
      { label: 'ID', key: 'id', align: 'center' },
      { 
        label: 'Name', 
        key: 'name', 
        align: 'left' 
      },
      { 
        label: 'Amount', 
        key: 'amount', 
        align: 'right',
        format: (value) => `$${value.toLocaleString()}`
      }
    ];

    // 3. Build HTML content
    const builder = new PDFTemplateBuilder();

    // Add header
    builder.add(generateHeader({
      title: 'Sales Report',
      subtitle: 'Monthly Summary',
      showDate: true
    }));

    // Add info section
    builder.add(generateInfoSection({
      'Period': 'January 2026',
      'Total Sales': data.length.toString(),
      'Status': 'Completed'
    }));

    // Add table
    builder.add(generateTable(columns, data));

    // 4. Generate and send PDF
    await PDFGenerator.sendPDFResponse(res, {
      html: builder.build(),
      filename: `sales-report-${dayjs().format('YYYY-MM-DD')}.pdf`
    });

  } catch (error) {
    console.error('Report generation error:', error);
    res.status(500).json({ error: 'Failed to generate report' });
  }
};
```

## Styling

### Default Styles

The system includes comprehensive default styles in [styles.ts](src/utils/pdf/styles.ts) covering:
- Typography
- Tables
- Headers and footers
- Info sections
- Utility classes

### Custom Styles

Add custom styles using the `customStyles` parameter:

```typescript
await PDFGenerator.sendPDFResponse(res, {
  html: content,
  customStyles: `
    .custom-class {
      background: #f0f0f0;
      padding: 20px;
    }
    h1 {
      color: #333;
      border-bottom: 2px solid #007bff;
    }
  `
});
```

### Utility Classes

Available utility classes:
- `.text-center`, `.text-left`, `.text-right` - Text alignment
- `.bold` - Bold text
- `.mt-10`, `.mt-20`, `.mb-10`, `.mb-20` - Margins
- `.page-break` - Force page break

## Multi-Page Reports

Use `addPageBreak()` to create multi-page reports:

```typescript
const builder = new PDFTemplateBuilder();

// Page 1
builder.add(generateHeader({ title: 'Page 1' }));
builder.add('<p>Content for page 1</p>');

// Add page break
builder.addPageBreak();

// Page 2
builder.add(generateHeader({ title: 'Page 2' }));
builder.add('<p>Content for page 2</p>');
```

## PDF Options

Customize PDF generation with `pdfOptions`:

```typescript
await PDFGenerator.generatePDF({
  html: content,
  pdfOptions: {
    format: 'A4',           // Paper format
    landscape: false,       // Orientation
    printBackground: true,  // Include backgrounds
    margin: {
      top: '20mm',
      right: '15mm',
      bottom: '20mm',
      left: '15mm'
    }
  }
});
```

## Browser Configuration

### Using System Chrome

Set the environment variable to use system Chrome:

```bash
# Windows
$env:PUPPETEER_EXECUTABLE_PATH = "C:\Program Files\Google\Chrome\Application\chrome.exe"

# Linux/Mac
export PUPPETEER_EXECUTABLE_PATH="/usr/bin/google-chrome"
```

### Production Deployment

For Docker/Cloud deployment, install chromium:

```dockerfile
# Dockerfile example
RUN apt-get update && apt-get install -y \
    chromium \
    chromium-driver
    
ENV PUPPETEER_EXECUTABLE_PATH=/usr/bin/chromium
```

## Performance Tips

1. **Browser Reuse**: The PDFGenerator uses a singleton browser instance that persists across requests for better performance.

2. **Cleanup**: Close the browser when shutting down your application:

```typescript
import { PDFGenerator } from './utils/pdf';

process.on('SIGTERM', async () => {
  await PDFGenerator.closeBrowser();
  process.exit(0);
});
```

3. **Optimize Images**: Use compressed images and consider data URIs for small logos.

4. **Limit Data**: For large datasets, consider pagination or summary reports.

## Troubleshooting

### Error: Could not launch browser

**Solution**: Install Chrome/Chromium or set `PUPPETEER_EXECUTABLE_PATH`

### PDF Not Generating

**Solution**: Check browser console logs and ensure HTML is valid

### Styles Not Applied

**Solution**: Ensure `printBackground: true` in PDF options

### Large PDFs Timing Out

**Solution**: Increase timeout or reduce data size
